# IEEE-IMT
O IEEE Mauá é o ramo estudantil do IEEE no Instituto Mauá de Tecnologia, reunindo estudantes de engenharia interessados em tecnologia e inovação. Promove projetos, palestras e workshops, conectando a comunidade acadêmica à engenharia elétrica, eletrônica e computação. Este site foi criado pela equipe para centralizar informações sobre a entidade.
